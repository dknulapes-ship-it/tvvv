# TVA Instalador - hecha por DKN Estudio

Instala la app de TV en Android TV / Google TV / convertidores Android y entra con la cuenta del cliente.

## Compilar
1. Subir TODO el contenido de esta carpeta a la raiz del repositorio (settings.gradle.kts debe quedar en la primera pantalla).
2. Pestana Actions > Build APK > esperar. Bajar el artefacto "TVAInstalador" (app-debug.apk).

## Requisitos
- Celular Android 7 o superior.
- TV/convertidor con Depuracion USB / ADB activada y en la misma red (hotspot del celu).
- La primera vez, aceptar el cartel "Permitir depuracion" en el TV.

## Ajustes ocultos
Mantener apretada la cabecera "TVA Instalador": IP manual (acepta ip:puerto), paquete, esperas y secuencia de teclas del login.
